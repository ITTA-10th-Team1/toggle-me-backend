# 0003. 아이템 기록 AI 추천 태그

- 상태: 확정
- 결정일: 2026-11-01

## 맥락

아이템 기록 화면에서 사진을 고르면 AI가 태그를 최대 3개 추천한다. 사용자는 0~3개를 골라 기록과 함께 저장하고, 이 태그를 모아 방 태그를 만든다.
MVP 범위 문서에는 "Spring AI + GPT"로 적혀 있었지만, iPhone 기본 촬영 형식인 HEIC를 OpenAI·Claude API는 받지 않는다.
서버는 t3.micro(heap 256MB)이고, 사진을 서버가 받아 AI로 넘기는 동기 방식은 10MB 사진 동시 10건에서 OOM으로 앱 전체가 재시작됐다.

## 결정

- 모델은 Gemini 3.1 Flash-Lite(`gemini-3.1-flash-lite`) 하나를 쓴다. Spring AI의 Google GenAI 스타터로 연결한다
- 사진 형식별로 모델을 나누지 않는다. 같은 사진이 OS(형식)에 따라 다른 태그 어휘를 갖게 되어 방 태그 집계가 갈린다
- 분석은 비동기로 한다. `POST /api/v1/images/analysis`가 202와 `analysisId`를 주고, 앱은 같은 화면에서 `GET`으로 결과를 조회한다
- 60초 안에 끝나지 않으면 `FAILED`로 응답하고, 앱은 태그 없이 기록을 이어간다
- JPEG·PNG는 Gemini가 S3 presigned URL을 직접 읽고, HEIC는 서버가 바이트로 보낸다(동시 1건)

## 결과

- 동기 대기 요청이 Tomcat 스레드를 붙잡지 않아 분석이 몰려도 로그인 등 다른 API가 멈추지 않는다
- 앱이 백그라운드에 갔다 오거나 네트워크가 끊겨도 `analysisId`로 결과를 다시 받을 수 있다
- 운영 서버에 `GEMINI_API_KEY`가 필요하다. 유료 등급 키여야 사용자 사진이 학습에 쓰이지 않는다
- 비슷한 옷·쇼핑 추천은 이번 범위에서 빼고 거울·책상 가구 기능에서 다룬다
