# 0002. 온보딩 방 공개 여부 전달 방식

- 상태: 확정
- 결정일: 2026-10-29

## 맥락

온보딩 첫 화면에서 사용자가 방 공개 ON/OFF를 고르고, 이 값은 최초 방 생성 시 반영된다.
토글을 누르는 시점에는 로그인 전이라 서버가 사용자를 식별할 수 없다.

## 결정

- 앱이 토글 값을 기기에 저장해 두었다가, 가구 선택 완료 요청(`POST /api/v1/members/onboarding`)에 `visibility`로 함께 보낸다
- `visibility`는 필수다. 누락되면 400으로 거절한다

## 결과

- 방과 공개 여부가 한 요청에서 함께 만들어져 어긋나지 않는다
- 값이 빠졌을 때 서버 기본값으로 의도치 않게 공개되는 일을 막는다. 화면의 기본값 ON은 앱에서만 쓴다
- 토글 값은 민감한 정보가 아니고, 회원은 토큰에서만 식별하므로 요청을 조작해도 본인 방 외에는 바꿀 수 없다
